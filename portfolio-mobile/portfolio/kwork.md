# Тексты для Kwork

## Шаг — трекер привычек
**Название:** Концепт: трекер привычек «Шаг» (30 симв.)
Мобильное приложение: онбординг, список привычек с отметками и кругом прогресса, календарь серий, добавление привычки с иконкой, цветом и расписанием.
Стек: React Native, Expo, TypeScript, expo-router, Reanimated. Светлая и тёмная темы.

## Ловко — запись в барбершоп
**Название:** Концепт: запись в барбершоп «Ловко» (34 симв.)
Мобильное приложение: выбор услуги с ценой и длительностью, выбор мастера, календарь со слотами времени и подтверждение записи.
Стек: React Native, Expo, TypeScript, expo-router, Reanimated. Тёмный графит и латунный акцент.

## Корзинка — доставка продуктов
**Название:** Концепт: доставка продуктов «Корзинка» (37 симв.)
Мобильное приложение: главная с поиском и акциями, каталог с фильтрами, карточка товара, корзина с адресом, временем доставки и итогом.
Стек: React Native, Expo, TypeScript, expo-router, SVG. Светлая тема, оранжевый акцент.

## Пульс — фитнес и тренировки
**Название:** Концепт: фитнес-приложение «Пульс» (34 симв.)
Мобильное приложение: план недели, тренировка с таймером отдыха по кругу, история с SVG-графиком нагрузки и профиль с целями.
Стек: React Native, Expo, TypeScript, expo-router, SVG, Reanimated. Тёмная тема, лаймовый акцент.

## Слушай — аудиокниги и подкасты
**Название:** Концепт: аудиокниги «Слушай» (28 симв.)
Мобильное приложение: подборки и «Продолжить слушать», карточка книги с главами, плеер со скоростью и таймером сна, библиотека с загрузками.
Стек: React Native, Expo, TypeScript, expo-router, SVG. Тёмно-синий фон, янтарный акцент.
