# «Пульс» — фитнес и тренировки

**Аудитория.** Люди 20–40 лет, тренирующиеся 3–5 раз в неделю в зале или дома, которым нужен понятный план и видимый прогресс.

**Настроение.** Тёмный фон, приглушённый лаймовый акцент (не кислотный), скруглённые карточки радиусом 24.

**Палитра (тёмная схема — основная).**
- Фон `#121410`, карточки `#1C1F18`, подложка `#262A1F`
- Акцент `#B7CF4A`, мягкий акцент `#2D3514`
- Текст `#F0F2EA`, приглушённый `#8F9684`

Светлая схема: фон `#F2F4EE`, акцент `#7E9A1E`.

**Шрифты.** Sora ExtraBold для цифр и таймера. Sora не содержит кириллицу, поэтому русский текст набран Onest — геометрическим гротеском со схожими пропорциями.

**Экраны.**
1. План на неделю — полоса дней, карточка сегодняшней тренировки, остальные дни.
2. Тренировка — упражнение, подходы, круговой таймер отдыха с обратным отсчётом.
3. История — SVG-график нагрузки по неделям, показатели, недавние тренировки.
4. Профиль — главная цель с кольцом прогресса, цели недели.
