# «Шаг» — трекер привычек

**Аудитория.** Взрослые 22–40 лет, которым важны спокойный ритм и маленькие победы; не нужна геймификация с наказаниями.

**Настроение.** Светлый мягкий минимализм: воздух, крупные круглые формы, пастельный зелёный.

**Палитра (светлая схема).**
- Фон `#F4F8F4`, карточки `#FFFFFF`, подложка `#E8F1E9`
- Акцент `#5FA97A`, мягкий акцент `#DCEEE2`
- Текст `#17261C`, приглушённый `#6B7D70`
- Оттенки привычек: `#7FB8D6`, `#E9B872`, `#C9A0DC`, `#EE9C8E`, `#8FC9B5`

Тёмная схема: фон `#121A15`, акцент `#76C493`.

**Шрифт.** Manrope (500–800).

**Экраны.**
1. Онбординг — три слайда со свайпом, индикатор страниц, кнопка «Далее / Начать».
2. Сегодня — круг общего прогресса, список привычек, отметка с пружинной анимацией.
3. Привычка — серия, календарь месяца, три показателя, столбцы недели.
4. Добавление — название, иконка, цвет, дни недели, время напоминания.
