# «Корзинка» — доставка продуктов

**Аудитория.** Горожане 25–45 лет, заказывающие продукты на вечер; важны свежесть, понятная цена и точное время доставки.

**Настроение.** Светлый, тёплый, аппетитный; крупные изображения товаров, свежий оранжевый акцент.

**Палитра (светлая схема).**
- Фон `#FFFAF4`, карточки `#FFFFFF`, подложка `#FFF0E0`
- Акцент `#F26B1D`, мягкий акцент `#FFE3CC`
- Текст `#2A1E14`, приглушённый `#8A7664`
- Зелёный `#7FB547`, красная метка скидки `#D9503F`

Тёмная схема: фон `#1D1610`, акцент `#FF8340`.

**Шрифт.** Nunito (600–900).

**Экраны.**
1. Главная — поиск, категории, баннеры акций, популярное.
2. Каталог — фильтры-чипы, сетка товаров с метками скидок, пустое состояние.
3. Карточка товара — крупное изображение, цена, количество, нутриенты, состав.
4. Корзина и оформление — позиции со счётчиком, адрес, окно доставки, итог.

**Изображения.** Товары нарисованы собственными SVG-иллюстрациями (`components/art/Product.tsx`).
