# «Ловко» — запись в барбершоп

**Аудитория.** Мужчины 20–45 лет, которые записываются с телефона за минуту и хотят видеть цену, время и мастера сразу.

**Настроение.** Тёмный графит, латунный акцент, строгая крупная типографика, чёткие прямоугольные формы.

**Палитра (тёмная схема — основная).**
- Фон `#1A1A1C`, карточки `#242426`, подложка `#2E2E31`
- Акцент латунь `#C9A55C`, мягкий акцент `#3A3225`
- Текст `#F2EEE6`, приглушённый `#9A968C`
- Линии `#38383B`

Светлая схема: фон `#F3EFE8`, акцент `#A07B34`.

**Шрифты.** Unbounded (заголовки), Inter (текст).

**Экраны.**
1. Выбор услуги — цена и длительность в каждой строке, итог в кнопке.
2. Выбор мастера — портрет, рейтинг, число отзывов, опыт.
3. Дата и время — горизонтальный календарь и сетка слотов, занятые зачёркнуты.
4. Подтверждение — мастер, дата, услуга, расчёт со скидкой, состояние «Запись подтверждена».
